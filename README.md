# pie-insurance

Pie Insurance — workers' compensation and small business commercial insurance, sold direct and through 4,000+ partner agencies. Profile covers the public Pie Partner API (OpenAPI 3.0.4: class-code search, appetite, eligibility, price indication, quoting, quote documents, and quote PDF) along with the company's product, agency, and corporate surfaces.

- Provider site: https://www.pieinsurance.com
- Partner API: https://www.pieinsurance.com/agency/api
- OpenAPI: [openapi/pie-insurance-partner-api-openapi.yml](openapi/pie-insurance-partner-api-openapi.yml)
- Swagger UI: https://api.post-prod.pieinsurance.com/api/docs/index.html
